# Glosario

[Volver a la guía](README.md)

| Palabra | Qué significa en Cooper |
| --- | --- |
| Administrador | Walter: gestiona accesos y recursos del equipo y aprueba las piezas de Marcas. |
| Aprendizaje | Lecciones y fallos registrados que ayudan a preparar el siguiente contenido. |
| Aprobación de guion | Primera revisión humana del video, antes de producir el montaje. |
| Aprobación final | Revisión humana del video terminado, antes de continuar hacia la publicación. |
| Avatar | Presentador visual. Usar uno propio requiere consentimiento y revisión. |
| Biblia del canal | Guía editorial: público, tono, reglas, personajes y estilo del canal. No se refiere necesariamente a la Biblia religiosa. |
| Borrador | Pieza guardada que aún necesita preparación y revisión. |
| Canal | Espacio editorial de la Fábrica para organizar videos. No equivale automáticamente a una cuenta social conectada. |
| Confirmar | Botón que ejecuta una acción propuesta en una tarjeta del chat o en una revisión de Operación. |
| Corpus bíblico cotejado | Conjunto de citas cuyo texto, referencia, versión y fuente revisó Walter. |
| Cuenta | Destino concreto en una red social, asociado a una marca. Es distinta de tu cuenta de acceso a Cooper. |
| Dueño | Persona a la que pertenece un recurso dentro de Cooper. Determina quién puede verlo y gestionarlo. |
| En vivo | La web está recibiendo actualizaciones de estado. No significa que una pieza ya esté publicada. |
| Estudio de la cuenta | Revisión del historial disponible de una cuenta propia conectada a una marca. |
| Fábrica | Recorrido que transforma una idea en un video con dos aprobaciones humanas. |
| Gancho | Comienzo que presenta una razón para seguir viendo el contenido. |
| Incidencia | Problema registrado que puede requerir una corrección o revisión. |
| Marca | Identidad con guía visual, tono, dueño, cuentas y piezas. |
| Métrica | Medida de un resultado, como vistas, me gusta, comentarios o retención. |
| Modo básico temporal | Respuesta de respaldo del chat con comprensión más limitada. |
| Pieza | Contenido preparado para una marca: imagen, carrusel, reel o historia, según la cuenta. |
| Programado | Con fecha de salida prevista. Todavía no equivale a publicado. |
| Publicado | La salida fue confirmada por el destino; en demostración, esa confirmación es ficticia. |
| Radar | Ideas y fuentes para un canal. En esta base no es un seguimiento de competidores. |
| Referencias | Material que orienta el contenido. En un video pueden ser enlaces e indicaciones; en Operación son personajes y escenarios. |
| Resultado incierto / conciliación | Falta comprobar si una acción llegó a completarse. Walter revisa el destino antes de repetirla para evitar duplicados. |
| Retención | Medida de cuánto permanece la audiencia viendo un video, según los datos que entregue la red. |
| Revisión | Versión concreta de una pieza. Editar una pieza de Marcas invalida su aprobación anterior. |
| Simulado / demostración | Ejemplo local. No acredita producción, envío ni publicación real. |
| Sin dato / sin datos | La medición no está disponible. No equivale a cero. |
| Storyboard | Plan de las escenas del video antes de producir sus imágenes y montaje. |
| Tarjeta del chat | Propuesta de acción con botones Confirmar y Cancelar. No se ejecuta solo por aparecer. |
| Zona horaria | Referencia con la que se interpreta una fecha y hora; por ejemplo, `America/Lima`. |
