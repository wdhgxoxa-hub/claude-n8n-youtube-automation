# Contratos de datos

El cerebro (routine de Claude) y n8n se hablan con JSON. Los formatos de cada `modo` están en `skill/FABRICA.md`.

Tablas de n8n (Data tables): fab_canales, fab_videos, fab_planos, fab_eventos, fab_costos, fab_trabajos.
Estados de un video: guion → aprobacion_guion → storyboard → aprobacion_storyboard → produccion → calidad → aprobacion_final → publicado.
